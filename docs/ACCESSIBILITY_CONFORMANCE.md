# Accessibility status

## Target

CommonGround AI targets WCAG 2.2 Level AA. It does not claim formal conformance until an independent audit is completed.

## Implemented design controls

- Semantic headings, landmarks, labels, lists, tables, and buttons
- Skip navigation
- Keyboard-operable workflows
- Visible focus treatment
- Responsive reflow with no horizontally scrolling primary navigation
- Descriptive image alternative text
- Text labels in addition to color and icons
- Reduced-motion behavior using the operating-system preference
- Typed alternatives when voice input is unavailable
- Bounded, readable error and status messages

## Required independent audit

- Keyboard-only completion of every workflow
- VoiceOver, NVDA, and/or JAWS testing
- Contrast, focus appearance, zoom, reflow, and touch-target checks
- Accessible names, descriptions, errors, and status announcements
- Tables, charts, dialogs, CAPTCHA/Turnstile, audio, and generated-content review
- Cognitive-load and plain-language usability testing
- Professional and community review of Spanish content

References: [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) and [Colorado HB21-1110](https://leg.colorado.gov/sites/default/files/2021a_1110_signed.pdf).
